About NSAT

Network Security Audit Tool — final year project

—

A lightweight auditing console for small networks

NSAT combines three classic security tasks — discovering whether a host is alive, enumerating the services it exposes, and judging how risky that exposure is — into one workflow that produces a single, explainable score and a downloadable PDF report.

1. Host Discovery

Scapy

Sends an ARP request on the local segment and falls back to an ICMP echo probe. A reply within the timeout marks the host as online and records latency.

2. Port Scanning

python-nmap

Runs a service-version scan (-sV) against a curated list of commonly abused TCP ports and returns each open port with its service and banner.

3. Risk Assessment

Custom algorithm

Each open service carries a weight based on how dangerous it is to expose. Weights are summed, an exposure penalty is added, and the result is capped at 100.

Scoring formula

score = min(100, Σ weight(service) + 3 × max(0, ports − 3))

0        Secure
1–20     Low
21–45    Moderate
46–70    High
71–100   Critical

Technology stack

Frontend: HTML5, CSS3, vanilla JavaScript, Chart.js · Backend: Python 3 + Flask · Database: SQLite · Scanning: Scapy, python-nmap · Reporting: ReportLab
